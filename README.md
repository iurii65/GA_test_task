2. Связывание номенклатуры и наценок (Приоритеты)

Для решения этой задачи была написана функция, которая для каждой строки проходит по справочнику наценок и присваивает наценку согласно установленному приоритету. Одновременно с этим проставляется номер группы приоритета.

3. Сравнительный анализ цен
Существует два основных подхода к формированию цен:

Индивидуальный подход: Для каждой номенклатуры присваивается собственный уровень наценки. Это позволяет гибко придерживаться стратегии компании, но в то же время не занижать цены по товарам, которые и так ниже, чем у конкурентов.

Групповой подход: Наценка регулируется для группы товаров. При такой схеме возможна ситуация, когда из-за товара с высокой себестоимостью придется сильно снижать маржинальность остальных товаров в этой группе.

Принятое решение для тестовой задачи:
Мы разделим популяцию товаров и выберем две группы для предложения внесения изменений наценки в справочник. По остальным товарам возьмем минимальную цену конкурентов и проверим, чтобы наценка не опускалась ниже 10%.
